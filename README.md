# Linked-IN Inserter

This started today, day 9/07/2026, as I was inserting job applications
A lot of those ask for LinkedIn links for your profile, and even if it was a 10 seconds thing I was getting a bit tired of opening LinkedIn all the time
A Pet peeve later and 5 sighs led me to use 1 hour to set up my Emacs editor and probably 2 days programming this with minimal help from LLMs (ALL LLM CODE WILL BE EXPLICITLY COMMENTED IDENTIFYING IT)

The purpose of this little extension for Chrome/Brave is so on the settings page one can set up their profile account and on job applications right click a single button that will fill the form field withoutmuch hassle
